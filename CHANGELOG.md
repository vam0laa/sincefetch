# Changelog

## 0.1.0 (2026-11-26)

First release.

- System block: OS, machine, uptime, packages, desktop, shell, terminal, CPU, GPUs, screen, memory, swap, disks, battery and its health.
- "Since your last look": packages updated, added, removed or downgraded (pacman and dpkg), restart needed, kernel change, disk growth, battery health, reboots, flatpak count.
- Block-art Arch logo in the terminal's own colours, framed layout with level bars, narrow-terminal handling.
- Settings file: sections and order, labels, colours, custom ASCII logo, custom lines from text, file or command.
- English and Turkish. `--json`, `--since`, `--changes`, `--info`.
